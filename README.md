# K-Food Launch — War Room

Situs war room untuk launch Korean food brand di Kediri: ghost kitchen first, delivery only, target 30+ order/hari sebelum bicara toko fisik.

- `index.html` — dashboard: strategi, filosofi produk, task list intern, progress bar, daily log
- `TUGAS-INTERN.md` — brief lengkap tugas intern fase riset (sumber konten situs)
- Gaya visual dicopy dari sidestudio.id (squiggle intro, cream/yellow, Instrument Sans/Serif)

## Update harian
1. Edit progress bar di `index.html` (`style="width:X%"` per task) — overall dihitung otomatis.
2. Tambah entri baru di section `#log` untuk hasil kerja harian.
3. Commit & push — GitHub Pages auto-update.
